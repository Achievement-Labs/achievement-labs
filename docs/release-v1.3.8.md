# Achievement Labs v1.3.8

- Event fixes now arrive from a separate signed catalog, so you no longer have to wait for an app release to get them. A cached catalog can no longer hide newer fixes.
- Each title updates on its own. A bad download for one title keeps that title's last good version and does not affect the others.
- The catalog refreshes while Auto Unlock is running. If a title's recipe changes partway through an achievement, that achievement restarts cleanly from the first request.
- Show the catalog status for each title.
- Fixes delivered through the catalog: the Modern Warfare 2 Campaign Remastered offset, Black Ops III achievements 3 and 10, and Battlefield Hardline achievements 134 and 135.
- Add custom timestamps for Windows 8 achievements and support Windows 8 titles in build, saved and transferred queues.

The release includes a pinned snapshot of the signed catalog, so event titles work before the first refresh. Existing stat recipes are preserved.
