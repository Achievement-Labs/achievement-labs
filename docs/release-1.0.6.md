# Achievement Labs v1.0.6

Download **AchievementLabs.exe** below for the updated Windows app. This release includes the application updates as well as the corrected event catalog.

## Xbox 360 profiles and achievements

- Discover Xbox 360 profiles on USB, extract a backed-up working copy, and browse local profiles, games, and achievements.
- Edit achievement states (locked, unlocked offline, or unlocked online) and online unlock timestamps. Stage edits, then save and verify a signed profile.
- Inject the signed working profile back to USB with a backup of the destination profile.
- Add games using local GPD files. Newly added games need a console sync before achievement editing becomes available.

## Games for Windows LIVE

- Native GFWL achievement workspace with process scanning, achievement browsing and search, refresh, and individual achievement submission.
- Dedicated GFWL library filter and improved title detection route PC GFWL games to their game-runtime workflow.

## Title Search and Windows 8

- Title Search checks DBox and Xbox achievement catalogs, displays verification status, and offers an Only verified achievements filter. Achievement-catalog verification means achievement records exist; unlocking availability is shown separately.
- Improved title/platform identification and a local GPD game-add action for Xbox 360 results.
- Windows 8 achievement loading combines catalog definitions with unlock history, handles pagination, and recognizes modern title aliases for several legacy games.

## Event catalog and file preservation

- Expanded and corrected the event catalog: **413 titles — 263 Supported, 147 Testing, and 3 Coming Soon**.
- FINAL FANTASY XV WINDOWS EDITION, FINAL FANTASY XV MULTIPLAYER: COMRADES (17 mapped IDs), Zoo Tycoon: Ultimate Animal Collection (59), and Rise of Nations: Extended Edition (38) are included. Zoo Tycoon and Rise of Nations currently retain their Testing flags; this release includes their mappings.
- Fixed catalog membership for six mapped titles, including COMRADES, Final Fantasy Type-0 variants, and FINAL FANTASY XVI.
- Application startup preserves existing local Events files and user edits.
- [Browse the complete title list](https://github.com/ethanwp28/achievement-labs/blob/v1.0.6/docs/title-support.md), including platforms, status, and mapped achievement counts. Status follows the author's classifications; counts describe available mappings, not all achievements in the game.
